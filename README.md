# 라이브 드래프트

코인으로 팀을 뽑는 실시간 팀 짜기 프로그램입니다. 자세한 기획은 [Live_Draft.md](./Live_Draft.md)를 참고하세요.

## 어떻게 동작하나요

1. 선생님이 방을 만들면 5자리 입장 코드가 발급됩니다. (주장 수, 학생당 코인 개수, 팀별 최소·최대 인원 설정)
2. 학생들이 코드로 입장하고, 선생님이 그중 일부를 주장으로 지정합니다.
3. 주장이 아닌 학생은 받은 코인을 원하는 주장들에게 자유롭게 나눠 겁니다. (합계는 지급받은 코인 수와 정확히 같아야 함)
4. 선생님이 제출을 마감하면, 모든 학생-주장 조합 중 가장 높은 코인을 건 학생부터 순서대로 팀이 정해집니다. 동점이면 룰렛 추첨 연출로 결정됩니다.
5. 결과는 효과음과 함께 한 명씩 실시간으로 발표됩니다. (선생님 화면·학생 화면 동시 반영)
6. 발표가 끝나면 최종 팀 구성이 남고, 선생님은 필요하면 팀을 수동으로 조정할 수 있습니다.

## 기술 스택

- **프론트엔드**: Vite + React (JavaScript)
- **실시간 동기화 / DB**: Firebase Realtime Database
- **로컬 세션 저장**: 브라우저 localStorage (내 이름, 내가 만든/참가한 방 기억)
- **효과음**: 외부 오디오 파일 없이 Web Audio API로 즉석 합성 (드럼롤, 발표음, 팡파레)

## 로컬에서 실행하기

Firebase 프로젝트가 아직 없어도 로컬 에뮬레이터만으로 전체 기능을 테스트할 수 있습니다.

```bash
npm install

# 터미널 1: Realtime Database 에뮬레이터 (Java 필요)
npm run emulators

# 터미널 2: 개발 서버
npm run dev
```

`.env.local`의 `VITE_USE_EMULATOR=true`(기본값)일 때 앱은 `127.0.0.1:9000` 에뮬레이터에 접속합니다.
에뮬레이터 UI는 http://127.0.0.1:4000 에서 방/참가자 데이터를 직접 확인할 수 있습니다.

## 실제 Firebase 프로젝트에 연결하기

1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트를 만들고 **Realtime Database**를 활성화합니다.
2. 프로젝트 설정 > 일반 에서 웹 앱을 추가하고 설정값을 확인합니다.
3. `.env.local`에 값을 채우고 `VITE_USE_EMULATOR=false`로 바꿉니다.
4. `firebase deploy --only database`로 `database.rules.json`을 배포합니다.

> ⚠️ 기본 `database.rules.json`은 로그인 절차 없이 빠르게 쓰기 위해 읽기/쓰기를 열어둔 상태입니다.
> 실제 서비스로 운영한다면 Firebase Authentication 등을 붙여 규칙을 강화하는 것을 권장합니다.
> 방 삭제 등 교사 전용 기능은 브라우저에 저장된 토큰으로만 구분되어 있어, 엄격한 보안이 필요한
> 환경에서는 충분하지 않습니다.

## 프로젝트 구조

```
src/
  lib/            팀 색상, 코인 검증, 드래프트 배정 알고리즘, 효과음, 로컬 저장소 등 순수 로직
  services/       Firebase Realtime Database 읽기/쓰기
  hooks/          방 데이터 실시간 구독 훅
  components/     코인 배분기, 발표 애니메이션, 색종이 효과, 결과표 등 공용 UI
  pages/          화면 단위 페이지 (홈, 방 만들기, 교사 콘솔, 참가, 학생 화면, 사용법)
```

## 사용법 탭 안내

`/guide`(사용법) 페이지의 각 단계 미리보기는 실제 화면 캡처 대신, 실제와 동일한 디자인 토큰으로 그린
축소 목업으로 구성했습니다. 실제 서비스로 배포한 뒤에는 진짜 스크린샷으로 교체하는 것을 권장합니다.
