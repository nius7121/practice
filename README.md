# Live Draft Program

`live_draft_prd.md`의 요구사항을 바탕으로 만든 애플 스타일의 미니멀한 라이브 드래프트 에디터입니다. 빌드 도구 없이 순수 HTML/CSS/JS로 동작하며, 브라우저에서 파일을 바로 열거나 정적 호스팅에 그대로 배포할 수 있습니다.

## 실행 방법

- 그냥 `index.html`을 브라우저로 열어도 대부분 기능이 동작합니다.
- 로컬 서버로 열고 싶다면 (드래그 앤 드롭·클립보드 API가 일부 브라우저에서 `file://`을 제한하는 경우 권장):
  ```
  npx serve .
  ```
  또는
  ```
  python -m http.server 5500
  ```

## 주요 기능

- **좌우 분할 실시간 에디터**: 왼쪽 패널에서 섹션을 추가·수정하면 오른쪽 프리뷰에 즉시 반영됩니다.
- **드래그 앤 드롭 순서 변경**: 섹션 카드의 `⋮⋮` 핸들을 잡고 드래그하면 순서를 바꿀 수 있습니다.
- **애플 스타일 디자인 시스템**: 글래스모피즘, 은은한 그림자와 보더, 부드러운 호버/트랜지션, 다크·라이트 모드(우측 상단 🌙/☀️ 토글, 시스템 설정 자동 감지).
- **시연(프레젠테이션) 모드**: 우측 상단 "시연 모드" 버튼 → 전체화면 포커스 뷰. 좌우 화살표 키 또는 하단 내비게이션으로 섹션 이동, `Esc`로 종료.
- **원클릭 Markdown 다운로드**: "다운로드 (.md)" 버튼으로 현재 드래프트를 표준 Markdown 파일로 즉시 저장.
- **공유 링크**: "공유하기" 버튼을 누르면 현재 내용을 URL 해시에 인코딩한 링크가 클립보드에 복사됩니다. 이 링크를 열면 동일한 드래프트가 그대로 복원됩니다. (백엔드 없이 URL만으로 동작하는 클라이언트 사이드 공유입니다.)
- **자동 저장**: 입력 내용은 `localStorage`에 자동 저장되어 새로고침해도 유지됩니다.

## 배포

### GitHub Pages
1. 이 폴더 전체를 GitHub 저장소 (`tjdr1517.github.io/prd` 등)에 push 합니다.
2. 저장소 Settings → Pages에서 배포 브랜치/폴더를 루트(`/`)로 지정합니다.
3. `https://tjdr1517.github.io/prd/`에서 바로 접속됩니다.

### Firebase Hosting (병행 지원)
저장소에 포함된 `firebase.json`을 그대로 사용하면 됩니다.
```
firebase login
firebase use --add   # 본인의 Firebase 프로젝트 선택
firebase deploy --only hosting
```

## 파일 구조

```
practice/
├─ index.html          # 마크업 (헤더, 좌우 패널, 시연 모드 오버레이, 토스트)
├─ css/style.css        # 애플 스타일 디자인 시스템 (라이트/다크 테마, 글래스모피즘)
├─ js/app.js            # 상태 관리, 렌더링, 드래그앤드롭, 마크다운 변환, 공유/다운로드 로직
├─ firebase.json        # Firebase Hosting 설정
└─ live_draft_prd.md    # 원본 PRD
```
